# 개인정보 및 권한

## 사용하는 기능과 권한

### Shizuku API 권한

삼성 자동 밝기 곡선 조회와 임시 패널 밝기 적용에 사용합니다. 사용자가 공식 Shizuku 앱에서 이 앱을 직접 허용해야 합니다. 앱 자체에 루트나 ADB 서버를 내장하지 않습니다.

### 포그라운드 서비스

보정 관리 중 주변 조도 변화를 계속 추적하기 위해 `FOREGROUND_SERVICE`와 `FOREGROUND_SERVICE_SPECIAL_USE`를 사용합니다. 사용자가 보정을 해제하면 서비스가 종료됩니다.

### 알림 (`POST_NOTIFICATIONS`)

보정 관리·일시중지·복원 대기 상태를 알리고 `보정 해제` 동작을 제공하는 데 사용합니다. Android 13 이상에서는 앱이 첫 실행에 한 번 표준 권한 창을 요청합니다. 거부한 권한을 강제로 변경하거나 반복 요청하지 않습니다.

### 부팅 완료 수신 (`RECEIVE_BOOT_COMPLETED`)

사용자가 `재부팅 후 다시 확인`을 켠 경우 재적용 대기 상태를 기록합니다. 비루트 Shizuku는 재부팅 후 중지되므로, Shizuku를 다시 시작하고 앱을 열어야 재적용할 수 있습니다.

### 조도 센서

Android의 `TYPE_LIGHT` 센서로 현재 주변 밝기(lux)를 읽습니다. 별도 런타임 권한은 필요하지 않으며 값은 기기 밖으로 전송하거나 이력으로 저장하지 않습니다.

## 사용하지 않는 권한

- 인터넷
- 위치
- 카메라
- 마이크
- 연락처
- 전화 및 문자
- 파일 전체 접근
- 접근성 서비스
- 다른 앱 위에 표시
- 시스템 설정 영구 변경

## 기기에 저장하는 데이터

앱 전용 `SharedPreferences`에 다음 상태만 저장합니다.

- 앱이 보정을 관리 중인지 여부
- 마지막 적용 보정 강도
- 재부팅 후 재적용 선택 여부와 대기 여부
- Shizuku 연결이 끊긴 상태에서 요청한 원래 값 복원의 대기 여부
- Android 알림 권한 창을 이미 요청했는지 여부

개인정보, 조도센서 이력, 화면 내용, 사용 앱 목록, Shizuku 자격증명은 저장하지 않습니다. 관리 상태는 클라우드 백업과 기기 간 전송에서 제외합니다.

## 네트워크

앱에는 인터넷 권한이 없으며 외부 서버로 데이터를 전송하지 않습니다. Shizuku의 시작 방식과 네트워크 사용 여부는 공식 Shizuku 앱의 정책을 따릅니다.

## 배터리 제한 예외

Wi-Fi 없는 야외 운용에서는 Samsung 백그라운드 관리가 Shizuku Binder 또는 이 앱을 동결하지 않도록 두 앱을 배터리 `제한 없음`과 `절전 상태로 전환하지 않을 앱`에 두는 것을 권장합니다. 이 설정은 데이터 수집 권한을 추가하지 않지만 기본 절전 정책보다 백그라운드 실행과 배터리 사용이 늘 수 있습니다.
