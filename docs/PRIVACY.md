# 개인정보 및 권한

## 사용하는 권한

### 시스템 설정 변경 (`WRITE_SETTINGS`)

자동 밝기 보정값을 읽고 쓰기 위해 필요합니다. Android의 특별 접근 화면에서 사용자가 직접 허용해야 합니다.

### 부팅 완료 수신 (`RECEIVE_BOOT_COMPLETED`)

사용자가 `재부팅 후 다시 확인`을 켠 경우 마지막 보정값을 한 번 재적용하기 위해 사용합니다. 상시 서비스는 실행하지 않습니다.

## 사용하지 않는 권한

- 인터넷
- 위치
- 카메라
- 마이크
- 연락처
- 전화 및 문자
- 파일 전체 접근
- 접근성 서비스
- 다른 앱 위에 표시

## 기기에 저장하는 데이터

앱 전용 `SharedPreferences`에 다음 값만 저장합니다.

- 앱이 보정을 관리 중인지 여부
- 앱 사용 전 원래 보정값
- 마지막으로 확인된 적용값
- 재부팅 후 재적용 선택 여부

개인정보, 조도센서 기록, 화면 내용, 사용 앱 목록은 저장하지 않습니다. 보정 관리 상태는 클라우드 백업과 기기 간 전송에서 제외합니다.

## 네트워크

앱에는 인터넷 권한이 없으며 외부 서버로 데이터를 전송하지 않습니다.
