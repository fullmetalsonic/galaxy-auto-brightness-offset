# 갤럭시 Z Fold8 실기기 시험계획

## 목적

PC 시험으로 확인할 수 없는 다음 항목을 폴드8에서 검증합니다.

- One UI가 `screen_auto_brightness_adj`를 실제 화면 밝기에 반영하는지
- 메인 화면과 커버 화면에서 모두 작동하는지
- 자동 밝기 변화 중 보정이 유지되는지
- 재부팅 후 설정이 유지되는지
- 원래 값 복원이 정확한지
- 시스템 언어에 따라 한국어 또는 영어 UI가 선택되는지

## 준비

1. 폴드8에서 자동 밝기를 켭니다.
2. USB 디버깅을 켜고 PC에 연결합니다.
3. 다음 명령으로 연결을 확인합니다.

```powershell
adb devices -l
```

4. 시험 전 보정값을 기록합니다.

```powershell
adb shell settings get system screen_auto_brightness_adj
```

값이 `null`이면 앱은 중립값 `0.00`으로 읽습니다.

## 설치

```powershell
adb install -r ".\app\build\outputs\apk\debug\app-debug.apk"
```

설치 후 앱을 열고 `시스템 설정 변경` 권한을 허용합니다.

## 기능시험

### T1. 권한 흐름

1. 권한이 없는 상태로 앱을 엽니다.
2. `권한 설정 필요`와 `권한 열기`가 표시되는지 확인합니다.
3. 권한을 허용하고 앱으로 돌아옵니다.

합격 기준: 별도 재실행 없이 `권한이 허용되어 있습니다`로 바뀝니다.

### T2. +10 적용 및 읽기 재확인

1. `+10` 프리셋을 선택합니다.
2. `선택한 보정 적용`을 누릅니다.
3. 성공 메시지와 현재 시스템 값 `0.10`을 확인합니다.
4. PC에서 다음 명령을 실행합니다.

```powershell
adb shell settings get system screen_auto_brightness_adj
```

합격 기준: 앱과 ADB가 모두 약 `0.1`을 표시하고 화면이 같은 환경에서 적용 전보다 약간 밝아집니다.

### T3. 자동 밝기 연동

다음 환경에서 `0`, `+10`, `+20`을 각각 비교합니다.

| 환경 | 확인사항 |
|---|---|
| 어두운 실내 | 최저 밝기가 과도하게 밝아지지 않는지 |
| 일반 사무실 | 사용자가 느낀 미세한 어두움이 개선되는지 |
| 창가 또는 밝은 실내 | 자동 밝기 상승이 계속 동작하는지 |
| 야외 | 고휘도 모드를 방해하지 않는지 |

합격 기준: 주변광 변화에 따른 자동 조절은 유지되고, 같은 환경에서는 양의 보정값이 전반적으로 더 밝게 보입니다.

### T4. 메인·커버 화면

1. `+10`을 적용합니다.
2. 커버 화면을 켜고 일반 사무실에서 확인합니다.
3. 폴드를 펼쳐 메인 화면에서 확인합니다.
4. 다시 접어 보정 상태와 앱 진단값을 확인합니다.

합격 기준: 두 화면 모두 자동 밝기가 유지되고 보정 효과가 나타납니다. 한쪽만 적용되면 FAIL로 기록합니다.

### T5. 외부 변경 감지

1. 앱에서 `+10`을 적용합니다.
2. 빠른 설정의 밝기 슬라이더를 직접 움직입니다.
3. 앱으로 돌아옵니다.

합격 기준: 시스템이 보정값을 바꿨다면 `외부 변경 감지`가 표시됩니다.

### T6. 재부팅

1. 앱의 `재부팅 후 다시 확인`을 켭니다.
2. 폴드8을 재부팅합니다.
3. 잠금 해제 후 앱과 ADB에서 값을 확인합니다.

합격 기준: 마지막 적용값이 유지되거나 앱이 한 번 다시 적용합니다. 상시 알림이나 상시 서비스가 없어야 합니다.

### T7. 원래 값 복원

1. `앱 사용 전 값으로 복원`을 누릅니다.
2. 앱과 ADB에서 시험 전 기록값을 확인합니다.

합격 기준: 시험 전 값과 일치하고 앱 관리 상태 및 재부팅 복원 설정이 해제됩니다.

### T8. 시스템 언어 전환

1. Android 시스템 언어를 한국어로 설정하고 앱을 다시 엽니다.
2. 앱 이름, 화면, 버튼, 상태 메시지와 복사한 진단정보가 한국어인지 확인합니다.
3. 시스템 언어를 영어로 바꾸고 앱을 다시 엽니다.
4. 같은 항목이 영어로 표시되는지 확인합니다.
5. 가능하면 한국어·영어가 아닌 제3의 시스템 언어에서도 앱을 열어 영어 기본 리소스가 사용되는지 확인합니다.

합격 기준: 한 화면에 두 언어가 동시에 표시되지 않으며, 한국어 시스템은 한국어, 그 외 시스템 언어는 영어를 사용합니다. 언어 전환 후 기능 상태와 저장값은 유지됩니다.

## 시각·사용성 시험

- 커버 화면 세로 상태에서 글자·버튼 잘림과 가로 넘침이 없어야 합니다.
- 펼친 화면에서는 2열 카드가 겹치지 않아야 합니다.
- 밝은 테마와 어두운 테마 모두 글자 대비가 충분해야 합니다.
- 권한 없음, 자동 밝기 꺼짐, 적용 중, 적용 성공, 외부 변경 상태가 색상뿐 아니라 문구로 구분되어야 합니다.
- 뒤로가기 후 권한 화면에서 복귀했을 때 앱 상태가 자동 갱신되어야 합니다.

## 검증 제한

조도센서의 lux 값과 실제 패널 휘도(nit)를 일반 앱만으로 정확하게 대응시키기 어렵습니다. 최종 평가는 ADB 설정값, 화면의 상대 변화, 사용자 체감, 메인·커버 화면 반복 결과를 함께 사용합니다.
